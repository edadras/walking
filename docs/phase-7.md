## جریان خرید

```
POST /orders {items:[{product_id, quantity}], address_id?}   Idempotency-Key: <uuid>   (امضاشده)
1. سفارشی با همین (user, key)؟ → همان
2. DB::transaction (تا ۳ تلاش در Deadlock):
   products FOR UPDATE (به ترتیب id) → بررسی‌ها → order(paid)
   → WalletService::debit('order:{id}')  ← InsufficientPoints = rollback کامل
   → UPDATE stock = stock - q WHERE stock >= q  ← ۰ ردیف = rollback
   → کدها: SELECT … FOR UPDATE LIMIT q (ناکافی = rollback) · کوپن: CouponService::issue
   → همه فوری؟ status = delivered
3. نقض UQ(user, key) در رقابت → سفارش برنده برگردانده می‌شود
```

## تصمیم‌ها

- **کلاینت فقط «چه و چند تا» می‌گوید**؛ قیمت، جمع و موجودی همیشه از سرور است.
- **یک کلید Idempotency برای هر Checkout** (نه هر ضربه)؛ تلاش دوباره پس از قطع شبکه هرگز دو بار خرید نمی‌کند.
- **کدهای دیجیتال رمزنگاری‌شده** ذخیره می‌شوند، در پنل هرگز نمایش داده نمی‌شوند (فقط ۴ کاراکتر آخر)، و فقط در جزئیات سفارش خود خریدار برمی‌گردند.
- **درگاه ریالی متصل نشده است:** پیاده‌سازی درگاه بدون مستند رسمی و قرارداد پذیرنده، کد ناامن و آزمایش‌نشده می‌ساخت. قرارداد `PaymentGateway` (`start`, `verify` سمت سرور) آماده است؛ با Bind کردن یک Adapter و روشن کردن Flag فعال می‌شود. تا آن زمان `payment_mode=money` با `payment_unavailable` رد می‌شود.
- **توضیحات کالا** در پنل Rich Text است و در اپ به متن ساده تبدیل می‌شود (بدون رندر HTML در اپ).

## تست‌ها

- Backend: ۱۷۹ تست (۱۴ تست جدید)، شامل **آزمون چندپردازه‌ای واقعی**:
  - ۸ خریدار هم‌زمان برای ۳ کد باقی‌مانده: دقیقاً ۳ خرید موفق، ۵ `out_of_stock`، بدون کسر امتیاز از بازنده‌ها، هر کد فقط یک بار.
  - ۶ سفارش هم‌زمان از یک کیف پول ۱۰۰ امتیازی با قیمت ۴۰: دقیقاً ۲ سفارش.
  - ۶ تکرار هم‌زمان با یک کلید: یک سفارش و یک کسر امتیاز.
  - خرید فیزیکی بدون نشانی، قیمت ارسالی کلاینت نادیده، کمبود امتیاز بدون تغییر موجودی، کد فقط برای خریدار، کوپن اسپانسر، سقف هر نفر، سطح، پرداخت ریالی غیرفعال، لغو و بازگشت، جلوگیری از بازگشت کوپن استفاده‌شده، دفترچه نشانی، ورود کد در پنل بدون نمایش کد، اقدامات سفارش در پنل و نقش‌ها.
- Flutter: ۶۷ تست (فروشگاه و قفل سطح، Checkout با یک کلید در تلاش دوباره و سقف تعداد، کمبود امتیاز، نمایش کد و خط زمانی، اعتبارسنجی نشانی و تبدیل ارقام فارسی).
